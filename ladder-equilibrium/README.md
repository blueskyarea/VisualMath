## 問題
質量M、長さLの一様で細く硬い棒ABを、なめらかで鉛直な壁と荒く水平な床との間に立てかけたところ、棒は静止した。
棒は壁に垂直な鉛直面内にあるものとし、床と棒のなす角をθ（0°＜θ＜90°）とする。
棒と床との間の静止摩擦係数μ、重力加速度の大きさをgとして、次の問に答えよ。
(1)棒が床から受ける垂直抗力と摩擦力の大きさをそれぞれ求めよ。
(2)この角度θで棒が静止したことからわかる静止摩擦係数μの大きさの範囲を不等式で表せ。

次に、棒の上端Bから距離xだけ離れた位置で、細くて軽い糸で質量mのおもりを棒につるした。このとき、棒は静止したままであった。
(3)棒が床から受ける垂直抗力と摩擦力の大きさをそれぞれ求めよ。
(4)この角度θで棒が静止したことからわかる静止摩擦係数μの大きさの範囲を不等式で表せ。


## (1) おもりなしの床からの力

鉛直方向のつり合いから、床からの垂直抗力は

\[
\boxed{N=Mg}
\]

である。

次に、床との接点 \(A\) まわりのモーメントを考えます。壁から棒への垂直抗力を \(R\) とすると、

`R(L × sinθ) = Mg(L/2 × cosθ)`
`R = Mg/2 × cosθ/sinθ = Mg/(2tanθ)`

水平方向のつり合いから、床の摩擦力の大きさ\(f\) は、\(R\) と等しいので、

\[
\boxed{f=\frac{Mg}{2\tan\theta}}
\]

となる。摩擦力は壁に向かう向きである。

## (2) 静止摩擦係数の条件

静止摩擦力の大きさ \(f\) は、最大静止摩擦力 \(\mu N\) 以下でなければなりません。
\(f\leq\mu N\)
(1)より、
\[
f=\frac{Mg}{2\tan\theta},
\qquad
N=Mg
\]なので、
\(\frac{Mg}{2\tan\theta}\leq\mu Mg\)
\(Mg>0\) で両辺を割ると、

\[
\boxed{\mu\geq\frac{1}{2\tan\theta}}
\]

となる。

## (3) 上端から距離 x の位置におもりをつるす場合

おもり `m` の位置は、下端 `A` から `L-x` である。
鉛直方向のつり合いより、
\[
N=Mg+mg
\]したがって、垂直抗力は
\[
\boxed{N=(M+m)g}
\]

次に、接点 \(A\) まわりのモーメントを考えます。
床からの垂直抗力を \(N\)、摩擦力の大きさを \(f\)、壁から棒への垂直抗力を \(R\) とします。
- 壁からの力 \(R\) の腕の長さ：\(L\sin\theta\)
- 棒の重力 \(Mg\) の腕の長さ：\(\frac{L}{2}\cos\theta\)
- おもりの重力 \(mg\) の腕の長さ：\((L-x)\cos\theta\)

よって、
\[
R(Lsinθ)=Mg((L/2)cosθ)+mg((L-x)cosθ)
\]
\[
R=g/tanθ × (M/2 + m(1 - (x/L)))
\]
水平方向のつり合いより、床の摩擦力の大きさは \(R\) に等しいので、
\[
\boxed{
f=\frac{g}{\tan\theta}
\left(\frac{M}{2}+m\left(1-\frac{x}{L}\right)\right)
}
\]

となる。

## (4) おもりがある場合の静止摩擦係数の条件

静止しているため、床で必要な摩擦力 \(f\) は最大静止摩擦力 \(\mu N\) 以下です。
\[
f\leq\mu N
\]
(3)より、
\[
N=(M+m)g
\]
\(f=
\frac{g}{\tan\theta}
\left(
\frac{M}{2}+m\left(1-\frac{x}{L}\right)
\right)\)
なので、
\[
\frac{g}{\tan\theta}
\left(
\frac{M}{2}+m\left(1-\frac{x}{L}\right)
\right)
\leq
\mu(M+m)g
\]
\(g>0\) で両辺を割ると、

\[
\boxed{
\mu\geq
\frac{\frac{M}{2}+m\left(1-\frac{x}{L}\right)}
{(M+m)\tan\theta}
}
\]

となる。

## 実行

このサンプルでは `M = 10 kg`、`m = 5 kg`、`L = 4 m`、`theta = 60 deg`、`g = 9.8 m/s^2`
としている。

```bash
python3 ladder-equilibrium/ladder_equilibrium.py
```

左上が(1)の自由物体図、右上が(2)の摩擦係数条件、左下が(3)のおもり付き自由物体図、右下が
(4)の摩擦係数条件である。おもりの位置 `x/L` が上端 `B` から下端 `A` へ動く様子を、左下と
右下で同期して表示する。
