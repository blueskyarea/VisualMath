## 問題
水平な地面上の点Oから小球を投射して、水平に距離Lはなれた点Pに落下させるための初速度の条件を考える。重力加速度の大きさをgとする。

(1)初速度の向きを水平から角θをなす向きとすると、初速度の大きさはいくらにすればよいか。2sinθcosθ=sin2θの関係を用いて求めよ。

(2) 初速度の大きさの最小値はいくらか。また、そのときのθはいくらか。

## 初速度

水平・鉛直方向の運動は

\[
x=v_0\cos\theta\ t
\]

\[
y=v_0\sin\theta\ t-\frac12gt^2
\]

で表される。出発点と到着点の高さが同じなので、着地時間は

\[
t=\frac{2v_0\sin\theta}{g}
\]

である。水平距離が `L` となる条件は

\[
L=v_0\cos\theta\cdot\frac{2v_0\sin\theta}{g}
=\frac{v_0^2\sin2\theta}{g}
\]

だから、

\[
\boxed{v_0=\sqrt{\frac{gL}{\sin2\theta}}}
\]

となる。

## 最小の初速度

`sin(2 theta)` は最大で `1` なので、初速度が最小なのは

\[
2\theta=90^\circ,\qquad \theta=45^\circ
\]

のときである。その最小値は

\[
\boxed{v_{0,\min}=\sqrt{gL}}
\]

となる。

## 実行

このサンプルでは `g = 9.8 m/s^2`、`L = 20 m` としている。

```bash
python3 projectile-range/projectile_range.py
```

軌跡を表す。右図は各角度に必要な初速度で、赤点が現在の角度、最も低い点が `45 deg` を示す。
