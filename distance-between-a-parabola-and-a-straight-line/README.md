## 問題
放物線 \(y=x^2\) 上の点Pと、直線 \(x-2y-4=0\) 上の点との距離の最小値を求める。
また、その時の点Pの座標を求める。

## 解説
放物線上の点を
\[
P(t,t^2)
\]とおきます。ここで \(t\) は点 \(P\) の \(x\) 座標です。
求めたいのは、「放物線上の点 \(P\)」と「直線 \(x-2y-4=0\)」との最短距離です。
これは、点 \(P\) から直線へ下ろした垂線の長さです。
点 \((x_0,y_0)\) と直線
\[
ax+by+c=0
\]との距離は
\[
\frac{|ax_0+by_0+c|}{\sqrt{a^2+b^2}}
\]で求められます。
今回、
\[
x-2y-4=0
\]なので、
\[
a=1,\qquad b=-2,\qquad c=-4
\]です。点 \(P(t,t^2)\) を代入すると、距離 \(d\) は
\[
d=
\frac{|t-2t^2-4|}{\sqrt{1^2+(-2)^2}}
\]\[
d=\frac{|t-2t^2-4|}{\sqrt5}
\]となります。
ここで、
\[
t-2t^2-4=-(2t^2-t+4)
\]です。また、
\[
2t^2-t+4
\]は常に正です。実際、平方完成すると
\[
\begin{aligned}
2t^2-t+4
&=2\left(t-\frac14\right)^2+\frac{31}{8}
\end{aligned}
\]となり、右辺は常に正です。
したがって絶対値を外して、
\[
d=
\frac{2t^2-t+4}{\sqrt5}
\]とできます。さらに平方完成した式を用いると、
\[
d=
\frac{
2\left(t-\frac14\right)^2+\frac{31}{8}
}{\sqrt5}
\]です。
\[
\left(t-\frac14\right)^2\geq0
\]なので、距離が最小になるのは
\[
t=\frac14
\]のときです。

このとき、
\[
d_{\min}=\frac{31/8}{\sqrt5}=
\boxed{\frac{31\sqrt5}{40}}
\]
となります。

また、
\[
P=\left(t,t^2\right)
\]
だから、
\[P=
\left(
\frac14,
\left(\frac14\right)^2
\right)\]

\[
\boxed{
P\left(\frac14,\frac1{16}\right)
}
\]
となります。
