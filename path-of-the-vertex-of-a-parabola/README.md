## 問題
放物線 \(y = x^2 + (2t - 10)x - 4t +16\) の頂点をPとする。
\(t\) が 0 以上の値をとって変化するとき、頂点Pの軌跡を求めよ。

## 解説
放物線は
\[
y=x^2+(2t-10)x-4t+16
\]で、まず頂点を求めるには、\(x\) について平方完成します。
※\(y = a(x - p)^2 + q\) の形に変形すること

\(\begin{aligned}
y
&=x^2+2(t-5)x-4t+16\\
&=\left(x+t-5\right)^2-(t-5)^2-4t+16
\end{aligned}\)

ここで、定数部分を整理すると、
\[
\begin{aligned}
-(t-5)^2-4t+16
&=-(t^2-10t+25)-4t+16\\
&=-t^2+6t-9\\
&=-(t-3)^2
\end{aligned}
\]

したがって、
\[
\boxed{
y=\left(x+t-5\right)^2-(t-3)^2
}
\]となります。

よって頂点 \(P\) の座標は、
\[
\boxed{
P\left(5-t,\;-(t-3)^2\right)
}
\]です。

ここで、頂点の \(x\) 座標を \(X\)、\(y\) 座標を \(Y\) とおきます。
\[
X=5-t
\]より、
\[
t=5-X
\]です。

これを
\[
Y=-(t-3)^2
\]へ代入すると、
\[
\begin{aligned}
Y
&=-\{(5-X)-3\}^2\\
&=-(2-X)^2\\
&=-(X-2)^2
\end{aligned}
\]となります。
※カッコは2乗されているので、中身を入れ替えてOK

したがって、頂点 \(P\) の軌跡を通常の \(x,y\) で書けば、
\[
y=-(x-2)^2
\]です。

ただし、問題では
\[
t\geq0
\]という条件があります。

\[
t=5-x
\]
なので、
\[
5-x\geq0
\]\[
x\leq5
\]という範囲の条件も必要です。

よって軌跡は、
\[
\boxed{
y=-(x-2)^2
\quad (x\leq5)
}
\]です。

これは頂点が \((2,0)\) の下に開く放物線のうち、\(x\leq5\) の部分です。端の点は、\(t=0\) のときの
\[
\boxed{(5,-9)}
\]であり、この点も含まれます。
