# 助走して塀を飛び越える車

高さ `h` の塀を、仰角 `45 deg` で跳んだ車が最高点ですれすれに越える。車は地上で最大加速度
`alpha` まで加速できるが、空中では加速できない。重力加速度を `g` とする。

## 塀の真上に達する時間

最高点での鉛直速度は 0 である。ジャンプ直後の鉛直速度を `vy` とすると、

\[
h=\frac{v_y^2}{2g}
\]

より、最高点に達する時間は

\[
\boxed{t=\sqrt{\frac{2h}{g}}}
\]

である。

## ジャンプ台直前の速さ

ジャンプ直後の速さを `v` とすると、`45 deg` なので

\[
v_y=v\sin45^\circ=\frac{v}{\sqrt2}
\]

である。これを高さの式へ代入すると、

\[
\boxed{v=2\sqrt{gh}}
\]

を得る。

## 最小助走距離

静止状態から最大加速度 `alpha` で加速すれば、助走距離を `s` として

\[
v^2=2\alpha s
\]

である。必要な速さ `v^2=4gh` を代入して、

\[
\boxed{s=\frac{2gh}{\alpha}}
\]

となる。

## 実行

このサンプルでは `g = 9.8 m/s^2`、`h = 5 m`、`alpha = 2 m/s^2` としている。

```bash
python3 car-jump-wall/car_jump_wall.py
```
