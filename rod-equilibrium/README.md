## 問題

重さ40N、長さ0.80mの一様な太さの棒を、次のように糸でつるして制止させた。
各図に示された糸の張力の大きさT1, T2 長さx を求めよ。
①
棒の左端の上向きにT1の張力がある。
水平から30°上向きに棒が伸びている。
棒の右端の上向きにT2の張力がある。
※この図にはｘは無い

②
棒の左端の上向きにT1の張力がある。
水平から真横に棒が伸びている。
棒の左端から0.60mの位置から上向きにT2の張力がある。
※この図にはｘは無い

③
棒の左端からxの位置から上向きにT1の張力がある。
真横に棒が伸びている。
棒の右端から下向きに20Nの張力がある。
※この図にはT2は無い

## 考え方

棒が静止するには、次の 2 条件が必要である。

1. 鉛直方向の力の和が 0
2. 任意の点まわりのモーメントの和が 0

一様な棒の重力 `40 N` は、棒の中心に作用する。モーメントは

```text
力の大きさ x 回転軸から作用線までの垂直距離
```

で計算する。力が鉛直なら、その垂直距離は水平方向の距離である。

## ① 両端で支持された 30 度の棒

棒の両端で上向きの張力 `T1`, `T2` を受ける。左端まわりのモーメントより、

```text
T2 (0.80 cos 30 deg) = 40 (0.40 cos 30 deg)
```

なので、`T2 = 20 N`。力のつり合い `T1 + T2 = 40` より、`T1 = 20 N`。

## ② 左端と 0.60 m の位置で支持された水平な棒

左端まわりのモーメントより、

```text
T2 x 0.60 = 40 x 0.40
```

となる。よって、

```text
T2 = 80/3 N,  T1 = 40/3 N
```

## ③ 1 本の糸と右端の下向き 20 N

上向き張力は、下向きの `40 N` と `20 N` の和なので `T1 = 60 N`。
左端まわりのモーメントより、

```text
60 x = 40 x 0.40 + 20 x 0.80
```

したがって、

```text
x = 8/15 m = 0.533 m
```
