# 投射した小球と自由落下する小球の衝突

原点から小球1を初速度 `v0`、角度 `theta` で投げると同時に、点 `P(x0, y0)` にある小球2を
静かに落下させる。重力加速度を `g` とする。

## 小球1が P の真下を通る時刻

小球1の水平方向の運動は

\[
x=v_0\cos\theta\ t
\]

である。`x=x0` より、

\[
\boxed{t=\frac{x_0}{v_0\cos\theta}}
\]

となる。

## その時刻の高さ

\[
y_1=v_0\sin\theta\ t-\frac12gt^2
\]

\[
y_2=y_0-\frac12gt^2
\]

先の時刻を代入すると、

\[
y_1=x_0\tan\theta-\frac{gx_0^2}{2v_0^2\cos^2\theta}
\]

\[
y_2=y_0-\frac{gx_0^2}{2v_0^2\cos^2\theta}
\]

である。

## 衝突する角度

衝突条件 `y1=y2` では、両方に共通する重力による落下量が打ち消される。

\[
x_0\tan\theta_0=y_0
\]

よって、

\[
\boxed{\tan\theta_0=\frac{y_0}{x_0}}
\]

となる。すなわち、小球1を点 `P` の初期位置に向けて投げれば、小球2が落下しても衝突する。

## 実行

このサンプルでは `x0 = 20`、`y0 = 15`、`v0 = 20 m/s`、`g = 9.8 m/s^2` としている。

```bash
python3 projectile-collision/projectile_collision.py
```
