## 問題
一直線上を互いに反対の向きに進んできた２つの物体AとBが正面衝突し、衝突後はどちらも初めと反対の向きに進んだ。
衝突前のAとBの速さはそれぞれ、4.0m/s, 1.6m/s であり、衝突後はそれぞれ、1.5m/s, 1.3m/s であった。2物体の間の反発係数を求めよ。

## 解説
反発係数 \(e\) は、衝突前後の相対速度の比で定義されます。
\[
\boxed{
e=
\frac{\text{衝突後の離れる速さ}}
{\text{衝突前の近づく速さ}}
}
\]1. 衝突前の相対速度
A と B は互いに反対向きに進んで正面衝突するので、近づく速さは和になります。
\[
4.0+1.6=5.6\ \mathrm{m/s}
\]2. 衝突後の相対速度
衝突後はどちらも進行方向が反対になっています。
- A は衝突前と反対向きに、速さ \(1.5\ \mathrm{m/s}\)
- B は衝突前と反対向きに、速さ \(1.3\ \mathrm{m/s}\)
したがって、2物体が離れる速さも和です。
\[
1.5+1.3=2.8\ \mathrm{m/s}
\]3. 反発係数
\[
e=\frac{2.8}{5.6}
\]\[
\boxed{e=0.50}
\]です。
反発係数は、それぞれの物体の速さの比ではなく、必ず「衝突後の相対速度 ÷ 衝突前の相対速度」で求めます。
