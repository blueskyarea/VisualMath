# 台上の鉛直部分 A-B を通る小球

なめらかな水平な床上の台には、鉛直な A-B、なめらかな曲面 B-C、水平な C-D がある。点 A と
点 B の高さは、最下点 C からそれぞれ `h1`, `h2` である。点 A で小球を静かに離す。

## A から B までの運動

小球が鉛直な A-B 上にある間、小球と台は同じ水平方向の速さをもつ。床がなめらかなので、小球と
台全体にはたらく水平方向の外力は 0 である。初めは静止しているため、台と小球の水平方向の速さは
ともに 0 のままである。

したがって、小球は A から B まで鉛直下向きに自由落下する。力学的エネルギー保存より、

\[
mgh_1=mgh_2+\frac12mv_B^2
\]

となる。よって、

\[
\boxed{v_B=\sqrt{2g(h_1-h_2)}}
\]

である。

## 実行

このサンプルでは `h1 = 4 m`、`h2 = 2 m`、`g = 9.8 m/s^2` としている。

```bash
python3 ball-platform-track/vertical_drop_to_b.py
```

小球が A から B へ鉛直に落下する間、台が水平方向に動かないことと、点 B に近づくほど小球の
鉛直方向の速さが増えることを確認できる。

## (2) 最初に点 C を通過するときの速さ

点 C では接線が水平である。小球は右向きに速さ `vC`、台は左向きに速さ `VC` で動く。水平方向の
運動量保存より、

\[
mv_C-MV_C=0
\]

力学的エネルギー保存より、

\[
mgh_1=\frac12mv_C^2+\frac12MV_C^2
\]

これらを連立して、

\[
\boxed{v_C=\sqrt{\frac{2Mgh_1}{M+m}}}
\]

\[
\boxed{V_C=\frac{m}{M}\sqrt{\frac{2Mgh_1}{M+m}}}
\]

を得る。小球は右向き、台は左向きである。

次のプログラムは、A-B では台が静止し、B-C では台が左へ反動する様子を表す。

```bash
python3 ball-platform-track/a_to_c_motion.py
```

## (3) C から D に到達するまでの時間

点 D の壁は台に固定されている。したがって床から見ると、小球は右向きに `vC`、壁は台とともに
左向きに `VC` で動く。小球と壁が近づく速さは、二つの速さの差ではなく和である。

\[
v_C+V_C
=v_C+\frac{m}{M}v_C
=\frac{M+m}{M}v_C
=\sqrt{\frac{2gh_1(M+m)}{M}}
\]

小球が点 C から壁 D まで進む、台に対する距離は `a` なので、

\[
t=\frac{a}{v_C+V_C}
\]

よって、

\[
\boxed{t=a\sqrt{\frac{M}{2gh_1(M+m)}}}
\]

次のプログラムでは、小球が右へ進むのと同時に、台と壁が左へ動く。そのため小球と壁の間隔が
`vC + VC` の速さで小さくなることを確認できる。

```bash
python3 ball-platform-track/c_to_d_motion.py
```

## (4) 壁 D と衝突した直後の速さ

右向きを正とする。衝突直前の小球の速度は `+vC`、台の速度は `-VC` である。衝突直後には
小球は左向きに速さ `vd`、台は右向きに速さ `Vd` となるので、速度はそれぞれ `-vd`, `+Vd` と表せる。

水平方向の運動量保存則より、

\[
-mv_d+MV_d=0
\]

反発係数の式より、

\[
v_d+V_d=e(v_C+V_C)
\]

これらと、衝突前の関係 `mvC = MVC` を用いると、

\[
v_d=ev_C,\qquad V_d=eV_C
\]

したがって、

\[
\boxed{v_d=e\sqrt{\frac{2Mgh_1}{M+m}}}
\]

\[
\boxed{V_d=\frac{em}{M}\sqrt{\frac{2Mgh_1}{M+m}}}
\]

小球は左向き、台は右向きである。次のプログラムは、壁 D との衝突を境に、両者の向きが反転する
様子を1つの図で表す。

```bash
python3 ball-platform-track/collision_at_d.py
```

## (5) B を越えた後の最高点の高さ

壁 D との衝突直後、小球と台の速さはともに衝突直前の `e` 倍である。そのため、衝突直後の系全体の
運動エネルギーは、最初に C を通過したときの `e^2` 倍である。

\[
\frac12mv_d^2+\frac12MV_d^2
=e^2\left(\frac12mv_C^2+\frac12MV_C^2\right)
=e^2mgh_1
\]

小球が B を越えて鉛直な部分を上がると、最高点では小球が一瞬静止する。鉛直部分では台と小球は
同じ水平方向の速度をもち、系の水平運動量は 0 なので、このとき台も静止する。したがって、全ての
運動エネルギーが小球の位置エネルギーになる。

\[
e^2mgh_1=mgh_3
\]

\[
\boxed{h_3=e^2h_1}
\]

次のプログラムは、D で跳ね返った小球が C、B を通過し、破線で示す高さ `h3` に達するまでを
1つの図で表す。サンプル値は、問題文どおり B を越えるよう `e^2 h1 > h2` にしている。

```bash
python3 ball-platform-track/return_to_highest_point.py
```
