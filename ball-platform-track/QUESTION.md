### 問題
なめらかで水平な床の上に、質量\(M[kg]\)の台が静止している。
台上の点A～Dは鉛直な同一平面内にあり、点Aから点Bにかけて鉛直、
点Bから点Cにかけてなめらかな曲面が続き、点Cから点Dにかけて水平となっている。
点A、Bはそれぞれ曲面の最下点Cより、\(h1, h2[m]\)の高さにあり、CD間の距離は\(a[m]\)である。

点Aで質量\(m[kg]\)の小球を静かに離した。
小球は点Bと点Cを通過して、点Dにある鉛直な壁に衝突してはねかえり、
点Cと点Bを再び通過してある高さの最高点まで到達した。

この間、小球は台から離れることなく点A～Dを含む鉛直な同一平面内のみを運動した。
小球と台、および台と床の間には摩擦はないものとし、
重力加速度の大きさを\(g[m/s^2]\)、点Dにある壁と小球の反発係数をeとする。
また、求める小球と台の速さは、床に対する速さである。

(1) 小球が最初に点Bを通過するときの小球の速さ\(vb[m/s]\)を\(g, h1, h2\) を用いて表せ。


### 解説(1)
点 A から点 B までの部分は鉛直です。小球はこの区間を鉛直下向きに運動します。
ここで、台が横向きに動く可能性を確認します。
小球が鉛直な部分 AB 上にある間、小球と台は同じ水平方向の速さをもつ必要があります。
台の水平方向の速さを \(u\) とすると、小球の水平方向の速さも \(u\) です。
床はなめらかなので、小球と台全体にはたらく水平方向の外力は 0 です。
最初は両方とも静止しているため、水平方向の運動量保存より、
\[
mu+Mu=0
\]\[
(M+m)u=0
\]\[
u=0
\]となります。
したがって、A から B までの間、台は動かず、小球は鉛直下向きにだけ運動します。
点 A の高さは \(h_1\)、点 B の高さは \(h_2\) なので、小球が下がる高さは
\[
h_1-h_2
\]です。
摩擦がないため、A から B の間で小球の力学的エネルギーは保存されます。
点 A では静かに離すので、速さは 0 です。
\[
mgh_1=mgh_2+\frac12mv_b^2
\]両辺から \(mgh_2\) を引くと、
\[
mg(h_1-h_2)=\frac12mv_b^2
\]\[
v_b^2=2g(h_1-h_2)
\]したがって、
\[
\boxed{
v_b=\sqrt{2g(h_1-h_2)}
}
\]です。

(2) 小球が最初に点Cを通過するときの小球の速さ\(vc[m/s]\)と
台の速さ\(Vc[m/s]\)をそれぞれ、\(g, h1, M, m\) を用いて表せ。

### 解説(2)
点 C は最下点なので、高さを 0 とします。
小球は点 A から点 C まで、全体として高さ \(h_1\) だけ下がります。
点 B の高さ \(h_2\) は途中の点なので、A から C までのエネルギーを直接考える場合には使いません。
点 C では軌道の接線が水平です。
- 小球は右向きに速さ \(v_C\)
- 台は左向きに速さ \(V_C\)
で動くとします。
1. 水平方向の運動量保存
床はなめらかなので、小球と台全体にはたらく水平方向の外力は 0 です。
初めは小球も台も静止しているので、全運動量は 0 です。
右向きを正にすると、点 C で
\[
mv_C-MV_C=0
\]となります。
したがって、
\[
\boxed{
V_C=\frac{m}{M}v_C
}
\]です。
ここで \(V_C\) は台の速さであり、向きは左向きです。
　
2. 力学的エネルギー保存
摩擦はなく、床から受ける力は仕事をしません。
したがって、小球と台を合わせた系の力学的エネルギーは保存されます。
点 A では静止しているので、初めのエネルギーは小球の位置エネルギーだけです。
\[
mgh_1
\]点 C では、小球と台の両方が運動しています。
\[
mgh_1
=
\frac12mv_C^2+\frac12MV_C^2
\]ここへ
\[
V_C=\frac{m}{M}v_C
\]を代入します。

\[
mgh_1
=
\frac12mv_C^2
+
\frac12M\left(\frac{m}{M}v_C\right)^2
\]
\[
mgh_1
=
\frac12mv_C^2
+
\frac{m^2}{2M}v_C^2
\]
\[
mgh_1
=
\frac12m\left(1+\frac{m}{M}\right)v_C^2
\]
\[
mgh_1
=
\frac12m\frac{M+m}{M}v_C^2
\]よって、
\[
v_C^2=
\frac{2Mgh_1}{M+m}
\]したがって、小球の速さは
\[
\boxed{
v_C=
\sqrt{\frac{2Mgh_1}{M+m}}
}
\]です。
台の速さは
\[
V_C=\frac{m}{M}v_C
\]より、
\[
\boxed{
V_C=
\frac{m}{M}
\sqrt{\frac{2Mgh_1}{M+m}}
}
\]です。
整理して書けば、
\[
\boxed{
V_C=
\sqrt{
\frac{2m^2gh_1}{M(M+m)}
}
}
\]とも表せます。
- 小球：右向きに \(\displaystyle \sqrt{\frac{2Mgh_1}{M+m}}\)
- 台：左向きに \(\displaystyle \frac{m}{M}\sqrt{\frac{2Mgh_1}{M+m}}\)
です。

(3) 小球が点Cを通過してから点Dに到達するまでの\(時間t[s]を g, h1, M, m, a\) を用いて表せ。
### 解説(3)
点 C から点 D までは水平であり、台に固定された距離は
\[
CD=a
\]です。
ここで重要なのは、点 D の壁も台 A に固定されているため、
台とともに左向きに動いていることです。
したがって、床から見た小球の速さ \(v_C\) だけで
\[
\frac{a}{v_C}
\]とはできません。小球が壁 D に近づく速さ、つまり小球の台に対する相対速度を使います。
点 C では、
- 小球：右向きに速さ \(v_C\)
- 台および壁 D：左向きに速さ \(V_C\)
です。
よって、小球が壁 D に近づく相対速度は、
\[
v_C+V_C
\]です。
したがって、C から D までにかかる時間 \(t\) は
\[
t=\frac{a}{v_C+V_C}
\]となります。
(2)より、
\[
v_C=
\sqrt{\frac{2Mgh_1}{M+m}}
\]\[
V_C=
\frac{m}{M}
\sqrt{\frac{2Mgh_1}{M+m}}
\]なので、
\[
\begin{aligned}
v_C+V_C
&=
\left(1+\frac{m}{M}\right)
\sqrt{\frac{2Mgh_1}{M+m}}\\
&=
\frac{M+m}{M}
\sqrt{\frac{2Mgh_1}{M+m}}
\end{aligned}
\]これを整理すると、
\[
v_C+V_C
=
\sqrt{\frac{2gh_1(M+m)}{M}}
\]です。
したがって、
\[
t=
\frac{a}{
\sqrt{\frac{2gh_1(M+m)}{M}}
}
\]\[
\boxed{
t=
a\sqrt{
\frac{M}{2gh_1(M+m)}
}
}
\]です。

(4) 小球が点Dにある壁と衝突した直後の小球の速さ\(vd[m/s]\)と
台の速さ\(Vd[m/s]\)をそれぞれ、\(g, h1, M, m, e\) を用いて表せ。
### 解説(4)
点 D の壁は台と一体なので、衝突は「小球」と「台」の1次元衝突として扱います。
点 C から D に着く直前の速さは、(2)より
\[
v_C=\sqrt{\frac{2Mgh_1}{M+m}},
\qquad
V_C=\frac{m}{M}v_C
\]です。右向きを正にとると、衝突直前の速度は
\[
\text{小球： }+v_C,
\qquad
\text{台： }-V_C
\]となります。
衝突直後、小球は左向き、台は右向きになります。その速さをそれぞれ \(v_d,\ V_d\) とすると、速度は
\[
\text{小球： }-v_d,
\qquad
\text{台： }+V_d
\]です。
1. 運動量保存則
床はなめらかなので、水平方向の外力はありません。
\[
m(+v_C)+M(-V_C)
=
m(-v_d)+M(+V_d)
\]衝突直前には、もともとの系全体の運動量が 0 です。実際、
\[
mv_C-MV_C=0
\]でした。
よって衝突直後も
\[
-mv_d+MV_d=0
\]すなわち
\[
\boxed{MV_d=mv_d}
\tag{1}
\]です。
2. 反発係数の式
衝突前の近づく速さは
\[
v_C+V_C
\]です。
衝突後は、小球が左、台が右へ進むため、遠ざかる速さは
\[
v_d+V_d
\]です。
よって反発係数 \(e\) より、
\[
e=
\frac{v_d+V_d}{v_C+V_C}
\]したがって、
\[
v_d+V_d=e(v_C+V_C)
\tag{2}
\]ここで (1) より
\[
V_d=\frac{m}{M}v_d
\]を (2) に代入すると、
\[
v_d+\frac{m}{M}v_d
=
e\left(v_C+\frac{m}{M}v_C\right)
\]両辺から
\[
\boxed{v_d=ev_C}
\]となります。
\[
\boxed{
v_d
=
e\sqrt{\frac{2Mgh_1}{M+m}}
}
\]小球は左向きです。
さらに、
\[
V_d=\frac{m}{M}v_d
\]なので、
\[
\boxed{
V_d
=
\frac{em}{M}\sqrt{\frac{2Mgh_1}{M+m}}
}
\]台は右向きです。

(5) 小球が曲面を上がり点Bをこえて最高点に達した時の、小球の点Cからの高さ \(h3[m]\) を \(g, h1, M, m, e\) のうち必要なものを用いて表せ。
### 解説(5)
衝突直後から最高点までの間は、摩擦も衝突もないので、小球と台全体の力学的エネルギーは保存されます。
点 D との衝突直後の速さは、(4) より
\[
v_d=e v_C,\qquad V_d=e V_C
\]です。

したがって、衝突直後の運動エネルギーは
\(\frac12mv_d^2+\frac12MV_d^2=
e^2\left(
\frac12mv_C^2+\frac12MV_C^2
\right)\)

点 C を最下点としたので、衝突直前、すなわち最初に C を通過したときには
\[
\frac12mv_C^2+\frac12MV_C^2=mgh_1
\]でした。

よって衝突直後の運動エネルギーは
\[
e^2mgh_1
\]となります。

小球が曲面を上がり、点 B を越えて最高点に着いたとき、小球は鉛直な A-B 上にあります。このとき小球は最高点で止まり、台も水平方向の運動量保存により止まります。したがって運動エネルギーは 0 です。

よって、点 C からの高さを \(h_3\) とすると、
\[
e^2mgh_1=mgh_3
\]\[
\boxed{h_3=e^2h_1}
\]です。

この結果には \(M,m,g\) は現れません。反発係数によって、衝突後に残る運動エネルギーが衝突前の \(e^2\) 倍になるためです。
