## 問題
質量1.4kgの台Aがなめらかで水平な床の上に置かれている。
この台Aの上面に、質量0.60kgの小物体Bが上面と同じ高さの水平面から乗り移った。
小物体Bが台Aの上面を動き出すと同時に、台Aも床の上を動き出し、
やがて、小物体Bと台Aは一体となって動き続けたとする。

乗り移った瞬間の小物体Bの速さを0.70m/s、台Aの上面と小物体Bとの間の動摩擦係数を0.25、重力加速度の大きさを9.8m/s^2とする。

(1) 一体となった後の小物体Bと台Aの速さV[m/s]を求めよ。

## 解説(1)
小物体 B が台 A の上を滑っている間、B と A の間には摩擦力がはたらきます。
しかし、この摩擦力は A と B を合わせた系で見ると内力です。

また、床はなめらかなので、A と B 全体にはたらく水平方向の外力は 0 です。

したがって、水平方向の運動量は保存されます。
右向きを正とします。
衝突・乗り移り直後
- 台 A は静止している
- 小物体 B の速さは \(0.70\ \mathrm{m/s}\)
よって、系全体の初めの運動量は
\[
0.60\times0.70
\]\[
=0.42\ \mathrm{kg\,m/s}
\]です。
一体となった後
A と B の合計質量は
\[
1.4+0.60=2.0\ \mathrm{kg}
\]です。
一体となった後の速さを \(V\) とすると、運動量保存より
\[
0.42=2.0V
\]\[
V=0.21\ \mathrm{m/s}
\]したがって、
\[
\boxed{V=0.21\ \mathrm{m/s}}
\]です。

(2) 一体になるまでに小物体Bが失った運動量の大きさは、
動摩擦力が小物体Bに与えた力積の大きさに等しい。
このことを用いて、小物体Bが台Aに乗り移ってから一体になるまでの時間Δt[s]を求めよ。

## 解説(2)
小物体 B が台 A に乗り移った直後は、
\[
v_{\mathrm{B,初}}=0.70\ \mathrm{m/s}
\]一体となった後は、(1)より
\[
v_{\mathrm{B,後}}=V=0.21\ \mathrm{m/s}
\]です。
B は右向きに進んでいますが、動摩擦力は左向きにはたらくため、B の運動量は減少します。
1. B が失った運動量
失った運動量の大きさは、
\[
m_{\mathrm B}(v_{\mathrm{B,初}}-v_{\mathrm{B,後}})
\]です。
\[
0.60(0.70-0.21)
\]\[
=0.60\times0.49
\]\[
=0.294\ \mathrm{N\,s}
\]です。
2. B にはたらく動摩擦力
動摩擦力の大きさは、
\[
f=\mu N
\]です。
B に対する垂直抗力は
\[
N=m_{\mathrm B}g
\]なので、
\[
\begin{aligned}
f
&=\mu m_{\mathrm B}g\\
&=0.25\times0.60\times9.8\\
&=1.47\ \mathrm{N}
\end{aligned}
\]です。
3. 力積と運動量変化
摩擦力が \(\Delta t\) 秒間はたらくと、その力積の大きさは
\[
f\Delta t
\]です。
問題文の通り、これは B が失った運動量の大きさに等しいので、
\[
1.47\Delta t=0.294
\]\[
\Delta t=\frac{0.294}{1.47}
\]\[
\boxed{\Delta t=0.20\ \mathrm{s}}
\]です。
摩擦力は B を減速させる一方、同じ大きさで反対向きの摩擦力が台 A を加速させます。したがって、B が失った運動量は A が得た運動量に等しくなります。
