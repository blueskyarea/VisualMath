## 問題
床からhの高さの地点から、小球を速さvで水平に投げ出した。
横をx軸、縦をy軸と定める。
重力加速度の大きさをgとする。
(1)小球が床に達する直前の速度のｘ成分とｙ成分をそれぞれ求めよ。

## 解説(1)
投げ出した地点を原点とし、
横向きを \(x\) 軸の正、鉛直上向きを \(y\) 軸の正とします。
初速度の成分は、
\[
v_{x0}=v,\qquad v_{y0}=0
\]です。

水平方向には力がはたらかないため、
\[
v_x=v
\]のまま変化しません。
鉛直方向には下向きに重力加速度 \(g\) がはたらくので、
\[
v_y=-gt
\]です。

床に達するまでの時間を \(t\) とすると、鉛直方向の変位は \(-h\) ですから、
\[
-h=-\frac12gt^2
\]\[
t=\sqrt{\frac{2h}{g}}
\]となります。

これを \(v_y=-gt\) に代入すると、

\(v_y=-g\sqrt{\frac{2h}{g}}\)
\(v_y=-\sqrt{2gh}\)

したがって、床に達する直前の速度成分は
\[
\boxed{v_x=v}
\]\[
\boxed{v_y=-\sqrt{2gh}}
\]です。

(2) 小球が床からはねかえった直後の、速度のX成分とY成分をそれぞれ求めよ。
小球と床の間の反発係数をeとし、床はなめらかであるとする。

## 解説(2)
\(x\) 軸は水平方向、\(y\) 軸は鉛直上向きを正とします。
(1)より、床に達する直前の速度成分は
\[
v_x=v
\]\[
v_y=-\sqrt{2gh}
\]です。
床はなめらかなので、床に平行な水平方向には摩擦力がはたらきません。
したがって、跳ね返りの前後で \(x\) 成分は変化しません。
\[
\boxed{v_x'=v}
\]次に、反発係数 \(e\) は、床に垂直な鉛直方向の速さの比です。
\[
e=
\frac{\text{跳ね返り後の上向き速度の大きさ}}
{\text{衝突前の下向き速度の大きさ}}
\]衝突前の鉛直方向の速さは
\[
\sqrt{2gh}
\]なので、跳ね返り後の鉛直方向の速さは
\[
e\sqrt{2gh}
\]です。
跳ね返り後は上向きなので、\(y\) 成分は正になります。
\[
\boxed{v_y'=e\sqrt{2gh}}
\]したがって、小球が床から跳ね返った直後の速度成分は、
\[
\boxed{(v_x',v_y')=\left(v,\ e\sqrt{2gh}\right)}
\]です。

(3) 小球が1回目にはねかえった後から、最高点 h´ に達するまでの時間を求めよ。
（床と1回目にぶつかった時を時刻0とする）

## 解説(3)
1回目に床から跳ね返った直後、鉛直方向の速度は
\[
v_y=e\sqrt{2gh}
\]です。
跳ね返った後は、重力により鉛直方向の速度が毎秒 \(g\) ずつ減少します。
時刻 \(t\) における鉛直方向の速度は、
\[
v_y=e\sqrt{2gh}-gt
\]です。
最高点では鉛直方向の速度が 0 になるので、
\[
0=e\sqrt{2gh}-gt
\]\[
t=\frac{e\sqrt{2gh}}{g}
\]したがって、
\[
\boxed{
t=e\sqrt{\frac{2h}{g}}
}
\]です。

(4) 2回目に小球が床にぶつかる点は、投げ出した位置からX方向にいくら離れているか。

## 解説(4)
投げ出してから1回目に床へ達するまでの時間は、
\[
t_1=\sqrt{\frac{2h}{g}}
\]です。
この間、水平方向の速度は常に \(v\) なので、1回目に床へぶつかる地点までの水平距離は
\[
x_1=v\sqrt{\frac{2h}{g}}
\]です。
次に、1回目の跳ね返り直後の鉛直上向き速度は
\[
e\sqrt{2gh}
\]でした。
跳ね返ってから、最高点までの時間は(3)より
\[
e\sqrt{\frac{2h}{g}}
\]です。
最高点から再び床へ落ちる時間も同じなので、
1回目の跳ね返りから2回目に床へぶつかるまでの時間は
\[
t_2=
2e\sqrt{\frac{2h}{g}}
\]です。

この間も水平方向の速度は \(v\) のままなので、跳ね返り後に進む水平距離は
\[
x_2=
v\cdot2e\sqrt{\frac{2h}{g}}
\]です。

したがって、投げ出した位置から2回目に床へぶつかる地点までの水平距離は、
\[
x_1+x_2
\]
\(=
v\sqrt{\frac{2h}{g}}
+
2ev\sqrt{\frac{2h}{g}}\)

\[
\boxed{
v(1+2e)\sqrt{\frac{2h}{g}}
}
\]です。
