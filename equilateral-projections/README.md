# Repeated Perpendicular Projections

## 問題
1辺の長さが3の正三角形ABCの辺ABの1点を\(P_1\)とし、\(AP_1＝2\)とする。
\(P_1\)から辺BCへの垂線\(P_1Q_1\)を下ろし、\(Q_1\)から辺CAへ垂線\(Q_1R_1\)を下ろし、\(Q_1\)から辺ABへの垂線\(R_1P_2\)を下ろす。
\(P_2\)からさらに同じ操作を繰り返して、\(Q_2\)、\(R_2\)、\(P_3\)、\(Q_3\)、\(R_3\)…とする。 線分\(AP_n\)の長さを求めよ。

## 解き方

求める長さを

\[
x_n=AP_n
\]

とおく。\(P_n\) は辺 \(AB\) 上にあるので、座標を使えば \(P_n\) の位置を \(x_n\) だけで表せる。

### STEP 1: 正三角形を座標上に置く

一辺が 3 の正三角形を次のように置く。

\[
A=(0,0),\qquad B=(3,0),\qquad C=\left(\frac32,\frac{3\sqrt3}{2}\right)
\]

\(P_n\) は \(AB\) 上であり、\(AP_n=x_n\) なので、

\[
P_n=(x_n,0)
\]

となる。最初の条件 \(AP_1=2\) から \(x_1=2\) である。

### STEP 2: \(P_n\) から \(BC\) への垂線の足 \(Q_n\) を求める

辺 \(BC\) 上の点は、実数 \(t\) を用いて

\[
B+t(C-B)
\]
※B を出発して、B→C の向きに t 倍だけ進んだ点。\(0<t<1\) のとき：B と C の間の点

と表せる。
\(P_nQ_n\) が \(BC\) に垂直であること、すなわち

\[
\bigl(P_n-Q_n\bigr)\cdot(C-B)=0
\]
※内積を使った垂直条件

を使う。
\(Q_n=B+t(C-B)\)に \(B, C の座標を代入すると\)、

\[
Q_n=\left(3-\frac{3t}{2},\frac{3\sqrt3t}{2}\right)
\]

であり、内積の式は

\[
\left(x_n-3+\frac{3t}{2},-\frac{3\sqrt3t}{2}\right)
\cdot\left(-\frac32,\frac{3\sqrt3}{2}\right)=0
\]

すなわち

\[
\frac92-\frac{3x_n}{2}-9t=0
\]

となる。よって、

\[
t=\frac{3-x_n}{6}
\]

となる。したがって、

\[
Q_n=\left(\frac{9+x_n}{4},\frac{\sqrt3(3-x_n)}4\right)
\]

である。

### STEP 3: \(Q_n\) から \(CA\) への垂線の足 \(R_n\) を求める

辺 \(CA\) は原点 \(A\) を通るので、その上の点は \(sC\) と書ける。ここで \(C\) は点 \(C\) の座標
\(\left(3/2,3\sqrt3/2\right)\) を、原点から \(C\) への位置ベクトルとして使っている。
\(Q_nR_n\) が \(CA\) に垂直、すなわち

\[
\bigl(Q_n-sC\bigr)\cdot C=0
\]

を用いる。これは

\[
s=\frac{Q_n\cdot C}{C\cdot C}
\]

と書ける。\(C ⋅ C\) は \(C\) 自身との内積であり、原点から \(C\) までの距離 \(|OC|\) の
2 乗を意味する。この問題では

\[
C\cdot C
=\left(\frac32\right)^2+\left(\frac{3\sqrt3}{2}\right)^2
=\frac94+\frac{27}{4}=9
\]

である。STEP 2 の \(Q_n\) を代入すると、

\[
Q_n\cdot C=\frac{3(9+x_n)}8+\frac{9(3-x_n)}8
=\frac{3(9-x_n)}4
\]

だから、

\[
s=\frac{9-x_n}{12}
\]

を得る。よって、

\[
R_n=\left(\frac{9-x_n}{8},\frac{\sqrt3(9-x_n)}8\right)
\]

となる。

### STEP 4: \(R_n\) から \(AB\) に下ろす

\(AB\) は \(x\) 軸なので、\(R_n\) から \(AB\) への垂線の足 \(P_{n+1}\) は、\(R_n\) の \(x\) 座標をそのまま持つ。

\[
P_{n+1}=\left(\frac{9-x_n}{8},0\right)
\]

従って漸化式は

\[
x_{n+1}=\frac{9-x_n}{8}
\]

である。

### STEP 5: 漸化式を解く

極限値になりそうな数を調べるため、\(x_{n+1}=x_n=x\) とおくと、

\[
x=\frac{9-x}{8}
\]

より \(x=1\) を得る。そこで \(y_n=x_n-1\) とおくと、

\[
y_{n+1}=x_{n+1}-1=-\frac18(x_n-1)=-\frac18y_n
\]

となる。初期値は \(y_1=x_1-1=1\) であるから、

\[
y_n=\left(-\frac18\right)^{n-1}
\]

である。したがって答えは

\[
\boxed{AP_n=1+\left(-\frac18\right)^{n-1}}
\]
※\(y_n=x_n-1\)　で　\(x_n=AP_n\)　なので、\(AP_n\) は、\(y_n + 1\) になる

となる。

### 確認

最初の数項は次の通り。

| \(n\) | \(AP_n\) |
| --- | --- |
| 1 | `2` |
| 2 | `7/8` |
| 3 | `65/64` |
| 4 | `511/512` |

偶数番目では 1 より小さく、奇数番目では 1 より大きい。差の大きさは毎回 \(1/8\) 倍になるため、\(AP_n\) は 1 を上下に交互にまたぎながら 1 に収束する。

## Run

正三角形 \(ABC\)（一辺 3）で、\(AP1 = 2\) とする。\(P -> Q -> R -> P\) の垂線投影を
繰り返す過程をアニメーションで表示する小さな Python プログラムです。

Python 3 を用意してから、matplotlib をインストールします。

```bash
python3 -m pip install -r requirements.txt
python3 triangle_projection.py
```

左の図が垂線投影の軌跡、右の図が \(AP_n\) の数列です。既定では \(P1\) から \(AP10\)
までを表示します。末尾の \(main(count=10, interval_ms=900)\) の値を変えると、表示する
点の数とアニメーション間隔を調整できます。

最後の \(P10\) を表示した後は、\(P1\) から繰り返し再生します。
