# 川を横切る船

流れの速さが `1.5 m/s`、川幅が `20 m` の川を船で渡る問題を可視化する。

## ベクトルの関係

船の速度は、どの立場から見るかで異なる。岸から見た船の速度は

\[
\vec{v}_{\text{shore}}
=\vec{v}_{\text{boat/water}}+\vec{v}_{\text{current}}
\]

である。プログラムでは、青が船の対水速度、緑が流速、赤が岸から見た速度を表す。

## (1) 船首を岸に垂直に向ける

\[
\vec{v}_{\text{boat/water}}=(0,2.0),\qquad
\vec{v}_{\text{current}}=(1.5,0)
\]

なので、

\[
\vec{v}_{\text{shore}}=(1.5,2.0)
\]

であり、速さは `2.5 m/s`。対岸方向の速さは `2.0 m/s` なので、時間は

\[
20 / 2.0=10\ \mathrm{s}
\]

となる。船は下流へ `15 m` 流される。

## (2) 岸から見て垂直に進むよう上流へ向ける

\[
\vec{v}_{\text{boat/water}}=(-1.5,2.0),\qquad
\vec{v}_{\text{current}}=(1.5,0)
\]

なので、下流・上流成分が打ち消し合い、

\[
\vec{v}_{\text{shore}}=(0,2.0)
\]

となる。岸から見た速さは `2.0 m/s`、時間は `10 s` である。

## 実行

プロジェクト直下で実行する。

```bash
python3 river-crossing/river_crossing.py
```

左図は (1)、右図は (2) を表す。矢印と点線の航跡を見比べると、(1) では下流へ流され、
(2) では上流への船の速度が流れを打ち消すことを確認できる。
