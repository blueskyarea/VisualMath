## 問題
ボールが速さ2.0m/sで床とのなす角が60°で衝突し、床と30°の角をなして跳ね返った。
ボールと床との間の反発係数はいくらか。答えは分数のままでOK。
床はなめらかで摩擦はないものとする。

## 解説
床がなめらかで摩擦がないため、衝突の前後で変化しないのは、床に平行な水平方向の速度成分です。
一方、反発係数 \(e\) は、床に垂直な方向、つまり鉛直方向の速度成分について、
\[
e=
\frac{\text{衝突後の鉛直方向の速さ}}
{\text{衝突前の鉛直方向の速さ}}
\]で定義されます。
1. 衝突前の速度成分
衝突前の速さは \(2.0\ \mathrm{m/s}\)、床との角は \(60^\circ\) です。
水平方向の速度成分は
\[
2\cos60^\circ=1
\]鉛直方向の速度成分の大きさは
\[
2\sin60^\circ=\sqrt3
\]です。
衝突前は下向きなので、速度を符号付きで書けば
\[
v_x=1,\qquad v_y=-\sqrt3
\]となります。
2. 衝突後の速度成分
床はなめらかなので、水平方向の速度成分は変わりません。
\[
v_x'=1
\]跳ね返った後、床との角は \(30^\circ\) です。跳ね返った後の速さを \(V\) とすると、
\[
V\cos30^\circ=1
\]\[
V\cdot\frac{\sqrt3}{2}=1
\]\[
V=\frac{2}{\sqrt3}
\]したがって、衝突後の鉛直方向の速度成分は
\[
v_y'=V\sin30^\circ
\]\[
v_y'=
\frac{2}{\sqrt3}\cdot\frac12
=
\frac{1}{\sqrt3}
\]です。跳ね返った後は上向きです。
3. 反発係数を求める
反発係数は、床に垂直な方向の速さの比なので、
\[
e=
\frac{1/\sqrt3}{\sqrt3}
\]\[
e=\frac13
\]したがって、
\[
\boxed{e=\frac13}
\]です。
注意として、反発係数は「衝突後の速さ ÷ 衝突前の速さ」ではありません。床に垂直な鉛直方向の速度成分の比です。
