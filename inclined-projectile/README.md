# 30度の斜面上の投射運動

水平と `30 deg` をなす斜面上の点 `O` から、斜面と `30 deg` の角をなす方向に速さ `V` で
小球を投げ上げる。斜面を上る向きを `x` 軸の正、斜面から垂直に離れる向きを `y` 軸の正とする。

## (1) 速度成分

重力加速度の成分は

```text
x 方向: -g sin 30 deg = -g/2
y 方向: -g cos 30 deg = -sqrt(3)g/2
```

である。初速度の成分と合わせて、

\[
v_x=\frac{\sqrt3}{2}V-\frac12gt
\]

\[
v_y=\frac12V-\frac{\sqrt3}{2}gt
\]

となる。

## (2) 位置

等加速度直線運動の公式を各方向へ使うと、

\[
x=\frac{\sqrt3}{2}Vt-\frac14gt^2
\]

\[
y=\frac12Vt-\frac{\sqrt3}{4}gt^2
\]

となる。

## (3) 斜面へ衝突する時刻

再び斜面上に戻るときは `y=0` である。`t=0` 以外の解は

\[
\boxed{t=\frac{2V}{\sqrt3g}}
\]

である。

## (4) 距離 OP

衝突時刻を `x` の式へ代入すると、

\[
\boxed{OP=\frac{2V^2}{3g}}
\]

となる。

## 実行

このサンプルでは `V = 10 m/s`、`g = 9.8 m/s^2` としている。

```bash
python3 inclined-projectile/inclined_projectile.py
```

左上から右下へ、(1)から(4)に対応する図を並べている。各グラフの点と右下の小球は同じ時刻を
表し、右下では斜面上の距離 `OP` で小球が再び斜面へ衝突する。
