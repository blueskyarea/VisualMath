# 水平飛行する飛行船からの落下

地上 `78.4 m` を水平方向に `20 m/s` で飛ぶ飛行船から、小球を静かに放す。
重力加速度は `9.8 m/s^2` とする。

## 飛行船から見た運動

小球は放す直前まで飛行船と同じ水平速度 `20 m/s` をもつ。飛行船も小球も水平方向に同じ
速さで進み続けるため、飛行船から見た小球の水平方向の速度は `0 m/s` である。

従って、小球は飛行船から見ると、初速度 0、加速度 `9.8 m/s^2` の**鉛直自由落下**をする。

## 落下時間

鉛直方向の運動は

\[
78.4=\frac12\times9.8\times t^2
\]

だから、

\[
t=4.0\ \mathrm{s}
\]

となる。

## 的までの水平距離

地面から見ると、小球の水平方向の速度は `20 m/s` のままである。落下時間 `4.0 s` の間に

\[
20\times4.0=80\ \mathrm{m}
\]

進む。したがって小球は、的の `80 m` 手前で放す必要がある。

## 実行

プロジェクト直下で実行する。

```bash
python3 airship-drop/airship_drop.py
```
