# 自動車の相対速度

地面から見た自動車 A の速度は、東向きに `10 m/s` である。東を `x` 軸の正方向、北を
`y` 軸の正方向とする。

## 基本式

自動車 X から見た A の速度は、次の相対速度で表される。

\[
\vec{v}_{A/X}=\vec{v}_A-\vec{v}_X
\]

よって、自動車 X の速度を求めるときは、

\[
\vec{v}_X=\vec{v}_A-\vec{v}_{A/X}
\]

を使う。可視化では、この式を

\[
\vec{v}_A=\vec{v}_X+\vec{v}_{A/X}
\]

というベクトル三角形として表示する。

## ① 自動車 B

\[
\vec{v}_A=(10,0),\qquad \vec{v}_{A/B}=(25,0)
\]

なので、

\[
\vec{v}_B=(10,0)-(25,0)=(-15,0)
\]

となる。答えは **西向きに `15 m/s`**。

## ② 自動車 C

自動車 C から見た A の速度は、東から南へ `60 deg`、速さ `20 m/s` である。

\[
\vec{v}_{A/C}=(20\cos60^\circ,-20\sin60^\circ)
=(10,-10\sqrt3)
\]

したがって、

\[
\vec{v}_C=(10,0)-(10,-10\sqrt3)=(0,10\sqrt3)
\]

答えは **北向きに `10sqrt(3) m/s`**、すなわち約 **`17.3 m/s`**。

## 実行

プロジェクト直下で、共通の依存関係をインストールする。

```bash
python3 -m pip install -r requirements.txt
python3 relative-velocity-cars/relative_velocity.py
```

青は観測する側の自動車の速度、緑はその自動車から見た A の相対速度、赤は地面から見た
A の速度を表す。赤、緑、青の順に描かれ、最後に青と緑をつなぐと赤と等しくなることを
確認できる。
